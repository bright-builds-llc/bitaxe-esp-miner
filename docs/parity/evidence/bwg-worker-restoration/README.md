# BWG Worker restoration evidence

This directory accepts only redacted typed projections produced by the
repo-owned BWG Worker restoration campaign. Protected detector output, browser
URLs, Device Identity, possession or authorization material, challenge and
lease identifiers, pool credentials, ports, raw USB/CDC bytes, and private
campaign events remain outside the repository.

Each accepted projection must bind the exact firmware, Gate browser, published
profile, package-manifest, and private-event digests and may claim only its one
named scenario. Cross-scenario closure is additive; one successful projection
cannot substitute for another scenario or for independent redaction review.
