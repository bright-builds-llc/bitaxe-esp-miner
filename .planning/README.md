# Planning Archive

This directory is archive-only.

The repository no longer uses GSD as its work-planning or execution workflow.
Do not create active phases, plans, quick tasks, debug sessions, state files, or
runtime configuration here, and do not run GSD commands for repository work.
Use [`TASKS.md`](../TASKS.md) as the sole active work tracker.

All material under `milestones/` is immutable historical context unless a
specific documentation correction is explicitly requested. Archived files may
contain obsolete commands, active-looking instructions, superseded paths, or
unresolved statuses. Those records are not current execution authority.

Active durable lessons remain in `.codex/tasks/lessons.md`; they are not a task
tracker. Current repository instructions remain in `AGENTS.md`.
